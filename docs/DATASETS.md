# Dataset and Split Policy

FoxMind uses public datasets through Hugging Face Datasets plus deterministic synthetic drills generated by the project code.

For benchmark-style datasets, the training pipeline intentionally uses **official training splits only** for gradient training. Validation/test examples are excluded from gradient training.

Local holdouts are carved from official training data for iterative checkpoint selection.

## Main data sources
- FineWeb-Edu — general language modeling
- FineMath — mathematical language modeling
- Cosmopedia — educational/general text
- WikiText-103 — language-model retention/evaluation
- GSM8K — math reasoning
- MATH — prealgebra, algebra, intermediate algebra, number theory, counting/probability
- SVAMP — arithmetic word problems
- HellaSwag — commonsense continuation
- ARC Easy / Challenge — science QA
- PIQA — physical reasoning
- WinoGrande — commonsense/coreference
- OpenBookQA — science QA
- CommonsenseQA — commonsense QA
- SciQ — science QA
- BoolQ — reading comprehension / yes-no
- OASST1 and Dolly 15K — general instruction/conversation data

Generated token binaries and large dataset caches are not committed to GitHub; the preparation scripts and manifests are included instead.
