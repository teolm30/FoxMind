# Devpost Submission Checklist

## 01 | Project Description
Use `docs/PROJECT_DESCRIPTION.md` on the Devpost project page.

## 02 | Source Code
This public GitHub repository contains source code, setup instructions, requirements, data-preparation scripts, results, and usage instructions.

## 03 | Demo Video
Record a 2–5 minute video and upload it to YouTube/Vimeo/Youku as public or unlisted. Use `docs/DEMO_SCRIPT.md`.

## 04 | Built With
Copy the complete list from `docs/BUILT_WITH.md`.

## 05 | Team Information
Devpost requires **real full names** for all team members. Add each teammate through their own Devpost account. Do not use aliases here.

## 06 | Screenshots
Upload at least 3 high-quality screenshots:
1. training/evaluation progress or loss/metrics;
2. V16 selected results;
3. live local model / technical setup.

See `screenshots/README.md`.
