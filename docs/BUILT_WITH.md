# Built With

## Languages and frameworks
- Python 3.11
- PyTorch 2.4.1
- torch-directml 0.2.5.dev240914
- Hugging Face Transformers 4.46.3
- Hugging Face Datasets 5.0.1
- NumPy 2.4.6
- Safetensors 0.8.0
- Hugging Face tokenizers / custom 8,192-token BPE tokenizer

## Model architecture
- Llama-style causal language model
- 49,430,016 parameters
- hidden size 512
- 15 transformer layers
- 8 attention heads
- 2 key/value heads
- 1,536 intermediate size
- 2,048 max positions
- tied input/output embeddings
