# Devpost screenshots

Devpost requires at least three high-quality images. Recommended captures:

1. **Training monitor / curve** — V16 training progress with active time, throughput, loss, and checkpoint evaluations.
2. **Evaluation results** — a clean table or terminal view showing the V16 selected metrics and the earlier-vs-selected checkpoint behavior.
3. **Technical setup / live inference** — FoxMind running locally, ideally with the terminal/model response and the local hardware visible in a separate system-info panel.

Do not fabricate benchmark screenshots. Capture the real saved run files and live model output.

Suggested 16:9 resolution: **1920×1080** or **1600×900**.
